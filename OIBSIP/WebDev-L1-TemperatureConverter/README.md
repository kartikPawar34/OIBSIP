# Temperature Converter Web App

An interactive temperature conversion tool built as part of the Oasis Infobyte Web Development & Designing Internship (Level 1, Task 3).

# Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

# Features
- Real-time numeric input validation.
- Simultaneous conversion across Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- Absolute zero boundary validation with user-friendly error messaging.
