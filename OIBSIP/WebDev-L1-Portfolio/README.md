# Personal Portfolio Website

A digital résumé and portfolio website built to showcase personal projects, skills, and contact details as part of the Oasis Infobyte Web Development & Designing Internship (Level 1, Task 2).

## Tech Stack
- HTML5
- CSS3
- JavaScript (for mobile navigation and interactivity)

## Features
- Profile/hero section with name, role title, and avatar placeholder.
- "About Me" section describing background and interests.
- Visual skills grid showcasing core technical competencies.
- Projects section highlighting portfolio works with GitHub link placeholders.
- Contact section with links/icons for communication.
- Responsive layout with smooth scroll navigation.
