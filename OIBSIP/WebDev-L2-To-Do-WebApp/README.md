# My Daily Tasks - To-Do List App

A simple, lightweight web application built with HTML, CSS, and Vanilla JavaScript to help you organize and track your daily tasks.

## Features

- **Add Tasks:** Quickly add new tasks via the input box or by pressing `Enter`.
- **Pending & Completed Lists:** Automatically separates tasks into Pending and Completed sections.
- **Inline Editing:** Edit existing task descriptions directly inside the list.
- **Task Counters:** Live counters showing the exact number of pending and completed tasks.
- **Timestamps:** Records the time a task was added and the time it was completed.
- **Local Storage:** Saves your tasks automatically in the browser so your list stays intact even after refreshing the page.
- **Empty State Messages:** Displays helpful messages when there are no tasks in a list.

## Project Structure

```text
├── index.html   # Main HTML structure
├── style.css    # Styling and layout
└── script.js    # Application logic and localStorage handling
```

## How to Run

1. Download or clone the project files into a single folder.
2. Open `index.html` in any web browser (Chrome, Firefox, Edge, Safari, etc.).
3. Start adding and managing your tasks!
