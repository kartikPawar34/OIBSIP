# Apex Trading — Landing Page

A visually polished static landing page designed for **Apex Trading**, a modern financial trading and investment platform, built as part of the Oasis Infobyte Web Development & Designing Internship (Level 1, Task 1).

## Tech Stack
- HTML5
- CSS3 (Flexbox & CSS Grid)

## Features
- **Sticky Navigation Bar:** Features quick-access links to core sections (Features, Markets, About, Contact) that stay fixed as users scroll.
- **Engaging Hero Section:** High-impact headline, subheadline, and a prominent "Get Started" call-to-action (CTA) button.
- **Distinct Content Sections:** Showcases core offerings, supported asset classes, platform features, and user testimonials.
- **Responsive Design:** Fully fluid layout built to scale smoothly across mobile phones, tablets, and desktop displays.
- **Professional Branding:** Utilizes a cohesive, finance-focused color palette, custom card layouts, and clean readable typography.
