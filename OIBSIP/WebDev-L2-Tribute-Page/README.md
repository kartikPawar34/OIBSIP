# Tribute Web Page to Dr. A.P.J. Abdul Kalam

A sleek, editorial dark-mode tribute website dedicated to the life, achievements, and legacy of **Dr. A.P.J. Abdul Kalam**—the Missile Man and People's President of India.

---

## Features

- **Modern Editorial Aesthetic:** Uses bold visual hierarchy inspired by luxury dark-mode editorial designs (`Syne`, `Inter`, and `Space Mono` typography).
- **Responsive Layout:** Optimized for all screen sizes, including desktop, tablet, and mobile views.
- **Key Sections Included:**
  - **Hero Summary:** Overview of Dr. Kalam's life and impact.
  - **Early Life & Education:** Context on his humble beginnings in Rameswaram and academic background.
  - **Major Contributions:** Highlighted achievements in the Indian Space Program, Missile Development (DRDO), Nuclear Tests (Pokhran-II), and Presidency.
  - **Timeline of Milestones:** Structured chronological view of key life events.
  - **Continuous Quotes Scroll:** Pure CSS marquee effect displaying inspirational quotes with smooth pause-on-hover interaction.
  - **Notable Literary Works:** Showcase of key authored books like *Wings of Fire* and *India 2020*.
  - **Civilian Honors:** Recognition of Padma Bhushan, Padma Vibhushan, and Bharat Ratna awards.

```text
    └── 1.png         # Background wallpaper / portrait graphic
```

---

##  Setup & Usage

1. **Clone or Download:** Save `index.html` and `style.css` in the same directory.
2. **Assets:** Ensure your background image is placed inside a `lib` folder named `1.png` (or update the background path in `style.css`).
3. **Launch:** Open `index.html` directly in any web browser.

---

##  Tech Stack

- **HTML5:** Semantic markup structure (`<section>`, `<article>`, `<header>`, `<footer>`).
- **CSS3:** Custom CSS with Grid, Flexbox, Keyframe animations, backdrop filters, and Google Web Fonts.
